# LeetCode Daily Challenges

Este repositório contém a minha jornada de resolução de desafios diários do LeetCode. O objetivo principal é aprimorar o pensamento algorítmico, a proficiência em estruturas de dados e a prática de linguagens de programação em cenários de alta performance.

## 🎯 Objetivo
O foco deste projeto é transitar entre a produtividade do Python — utilizada para rápida prototipagem e análise lógica — e a performance do C++, aplicada em situações onde o controle de memória e a velocidade de execução são críticos.

## 🛠️ Tecnologias
Os desafios estão organizados e resolvidos utilizando:
- Python: Foco em legibilidade, expressividade e rapidez na implementação de soluções gananciosas (greedy) e de complexidade linear.
- C++: Foco em eficiência, gerenciamento de recursos e otimização de algoritmos para atingir os limites de tempo mais rigorosos dos juízes online.

## 📈 Foco de Aprendizado
Além de resolver os problemas, busco documentar e aplicar conceitos fundamentais de computação, tais como:
- Análise de Complexidade: Estudo constante de notação Big O para garantir soluções eficientes ($O(N)$, $O(N \log N)$).
- Estruturas de Dados: Uso estratégico de Hash Maps, Heaps, Linked Lists e Vetores.
- Tradução entre Paradigmas: Prática de converter soluções dinâmicas de alto nível (Python) para implementações de baixo nível e estaticamente tipadas (C++).

## 🚀 Como este repositório me ajuda no desenvolvimento
Entender a base de algoritmos não apenas resolve problemas em competições, mas é o alicerce para áreas de engenharia de software de alto nível, como:
- Game Development: Conhecimento de C++ necessário para Unreal Engine.
- Sistemas de Alta Performance: Otimização de código que impacta diretamente a experiência do usuário final.
 
Este é um projeto de evolução constante. As soluções aqui contidas refletem meu progresso na compreensão das melhores práticas de codificação.
